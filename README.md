## 🏛️ What is AlumNetwork?

AlumNetwork bridges the gap between students and their college alumni — not as a social network, but as a **structured career pipeline**. It enables students to discover alumni, trace their career paths, find startups where alumni already work, build targeted projects, get them validated, and send credibility-backed cold emails — all in one place.

The platform now features a **fully integrated FastAPI backend** with **LLM-native discovery** for startups and tech events.

```
Discover Alumni → Trace Their Path → Find a Startup → Build for It → Get Validated → Send the Email → Get Hired
```

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) v18+ & npm v9+
- [Python](https://www.python.org/) 3.10+
- A Google Gemini API Key

### Installation

1. **Clone & Frontend Setup**:
   ```bash
   git clone https://github.com/your-username/alumnetwork.git
   cd alumnetwork
   npm install
   ```

2. **Backend Setup**:
   ```bash
   # Install dependencies
   pip install fastapi uvicorn openai-python python-dotenv
   ```

### Environment Setup

Create a `.env` file in the `backend/` directory:

```env
LLM_API_KEY=your_gemini_api_key_here
LLM_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai/
LLM_MODEL=gemini-2.0-flash-exp
```

### Run Locally

You need to run both the frontend and backend servers:

**Start Backend (Port 8000)**:
```bash
$env:PYTHONPATH="."
python -m uvicorn backend.main:app --port 8000
```

**Start Frontend (Port 3000)**:
```bash
npm run dev
```

The app will be available at **http://localhost:3000**. The Vite dev server is pre-configured to proxy `/api` requests to the FastAPI backend.

## 🎨 Design System

AlumNetwork uses a custom design language — **academic-elite editorial dark mode**, inspired by institutional permanence.

- **Film grain** — SVG fractalNoise overlay at 3.5% opacity
- **Glassmorphism** — `backdrop-blur-sm` on all cards
- **Typography** — Cormorant Garamond (Editorial) & Playfair Display (Heading)
